# Entwürfe für die Interview-Strukturierung

Diese drei Bilder sind **noch nicht für die Website freigegeben**. Sie dienen der gemeinsamen Abstimmung:

- `lupe-entwurf.png` – neugieriger Waschbär für einen Abschnittseinstieg
- `sprechblase-entwurf.png` – Waschbär für einen besonderen Gedanken oder ein Zitat
- `wegweiser-entwurf.png` – Waschbär als Hinweis auf das nächste Kapitel

Der Lupen-Entwurf passt bereits am besten zur ruhigen Website-Gestaltung. Sprechblase und Wegweiser besitzen im aktuellen Entwurf einen zu starken blauen Leuchteffekt. Sie werden deshalb nicht in eine sichtbare HTML-Seite eingebunden, bevor eine bereinigte Fassung ausdrücklich freigegeben wurde.

## Gemeinsame Vorgaben

- dieselbe Figur und Zeichenfamilie wie die freigegebene Körperstudie
- dunkle blaue Kontur, graues Fell, helle Schnauze und Stirnzeichnung
- dunkle ovale Augen mit kleinem gedämpftem Reflex
- kleine Begleitfigur, keine Lehr- oder Autoritätsperson
- transparenter Hintergrund ohne Leuchteffekt
- kein Text im Bild
- höchstens ein Strukturierungsbild pro Interviewkapitel

Die Bildentwürfe wurden mit generativer KI auf Grundlage der freigegebenen Waschbärstudie ausgearbeitet.
